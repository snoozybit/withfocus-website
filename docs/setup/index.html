Set up Focus

Focus reads what reaches you in Slack and email, drafts replies in your voice, and keeps track of what your coding agents (Claude Code, Cursor, Codex) are working on. This guide takes about ten minutes. Steps 1 to 4 are for everyone; step 5 is for whoever runs your team's databases.

Before you start

A Mac or Linux computerFocus runs a small background service on it.
Your work emailYou sign in with a code sent to it. No password.
Slack and GoogleThe accounts you want Focus to read.

Focus never sends anything as you on its own. Every reply it writes is a draft that only you can see, until you press Send as me.

1Sign in to Focus

  1. Open api.withfocus.io.
  2. Enter your work email and press Sign in.
  3. Type the 6-digit code from the email Focus sends you.

This creates your Focus account. If a teammate invited you to their workspace, you'll see it here; otherwise you start in your own. Keep this tab open: you'll use it in the next step.

2Install Focus on your computer

Open a terminal and run:

curl -fsSL https://api.withfocus.io/install.sh | bash

The installer checks the download's checksum, puts focus in ~/.local/bin (no admin rights needed), and starts focus setup. Setup then:

  1. Asks for your email and prints a link and a short code.
  2. Open the link in the browser where you signed in, check the code matches, and press Approve. Your computer is now signed in for 30 days at a time, and it refreshes by itself.
  3. Starts the Focus background service, which runs whenever you're logged in.
  4. Adds the Focus skill and chat hooks to Claude Code, Cursor and Codex, if you have them. Your coding chats then show up in Focus as agents, and they can use Focus with the focus tools command.

To check it worked: focus version prints a version number, and your computer appears on the Nodes page of the dashboard.

3Connect Slack

  1. On the dashboard, open Tools.
  2. On the Slack tile, press Connect.
  3. Pick your Slack workspace and press Allow.

Focus then reads your DMs and the messages that mention you. When something needs a reply, a draft appears in that conversation, visible only to you, with three buttons:

  • Send as me posts it as you.
  • Edit lets you change it before sending.
  • Dismiss removes it.

When Focus needs your input instead, it asks you in a DM from the Focus bot, with a link to the message. Reply in that thread.

If Slack says an admin has to approve the app, ask your Slack admin to approve Focus, then press Connect again.

Want Focus to run through a Slack app your company owns? An admin can set that up in a few minutes: Your own Slack app.

4Connect Gmail

  1. On Tools, press Connect on the Gmail tile.
  2. Choose your Google account.
  3. Review the access and press Allow. One connection covers Gmail, Calendar and Drive.

Focus scans recent email for what's waiting on you: replies people expect, things you promised, deadlines. The tile then shows Connected. Zoho Mail users connect from the Zoho Mail tile the same way.

5Team databases with an Outpost admins

An Outpost lets your team's agents query your Postgres and MySQL databases, read-only. It runs inside your network: queries go from a teammate's computer straight to the Outpost, and the results never pass through Focus. Every query is signed and audited, and the Outpost stops serving if Focus can't see its audit trail.

Create it and install it

  1. On the dashboard, open Outposts and press Add an outpost.
  2. Give it a name, such as prod-vpc, and press Create and get install command.
  3. On a server inside your network that can reach your databases, run the command the dashboard shows. It carries a one-time code that works for 15 minutes. It looks like this:

Linux (installs a system service):

curl -fsSL https://api.withfocus.io/outpost/install.sh | sudo sh -s -- --enroll ENR-XXXXX-XXXXX-XXXXX

macOS (installs a launch agent):

curl -fsSL https://api.withfocus.io/outpost/install.sh | sh -s -- --enroll ENR-XXXXX-XXXXX-XXXXX

Replace the ENR-… code with the one from your dashboard. Copying the whole command from the dashboard is easiest.

Approve it

  1. The install prints a key fingerprint, starting SHA256:.
  2. On the Outposts page, the new Outpost waits for approval. Check its fingerprint matches the one the install printed, then approve it.

Add your databases

Use a read replica and a database user that can only read. Run this in a terminal; it asks for the password without showing it, so the password never goes into a chat or a file:

focus workspace database add postgres prod --host db.internal --database app --username focus_readonly

Use mysql instead of postgres for MySQL. Optional flags: --port, --description (tell agents what's in it), --ssl-mode, --max-rows (default 1000), --outpost.

Teammates' computers reach the Outpost on port 7443, over your office network or VPN. For failover, run two Outposts that serve the same databases.

Keeping Focus up to date

When a new version is out, Focus tells you. To update:

focus upgrade

This also updates the Focus skill and hooks in Claude Code, Cursor and Codex. Restart any coding chats you have open so they pick it up.

If something goes wrong

focus: command not found
Open a new terminal window. The installer added ~/.local/bin to your PATH, and only new terminals see it.
The approval link expired
Run focus frontdesk login to get a new link and code.
The dashboard says no computer is connected
Run focus frontdesk install --now to restart the background service.
"checksum mismatch" during install
Nothing was installed. Wait a minute and run the install again.
Focus signed you out on this computer
You'll get a notification. Run focus frontdesk login and approve it in the browser.
