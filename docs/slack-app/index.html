Your own Slack app

Run Focus in Slack through an app your company owns. You create it from our manifest in a couple of minutes, and Focus connects to it over Socket Mode: Slack never calls in to Focus, so there's no request URL to set up. You need to be a Focus workspace admin, and allowed to create apps in your Slack workspace.

Why your own app

  • The bot is yours: it appears under your company's apps, with your name and icon if you change them.
  • Your Slack admin approves and controls it, like any app your company runs.
  • You can remove it at any time from Slack, which cuts Focus off immediately.

1Create the app from the manifest

  1. Go to api.slack.com/apps and press Create New App.
  2. Choose From a manifest, pick your Slack workspace, and press Next.
  3. Choose the YAML tab, replace what's there with the manifest below, and press Next.
  4. Review the summary and press Create.
# Focus: Slack app manifest for your own workspace.
# Setup guide: https://withfocus.io/docs/slack-app/
#
# At api.slack.com/apps: Create New App > From a manifest > pick your
# workspace > paste this file. It uses Socket Mode, so Slack needs no
# request URLs: Focus connects out to Slack with the app-level token.
display_information:
  name: Focus
  description: Reads what reaches you in Slack and drafts replies in your voice. Nothing is sent until you press Send.
  background_color: "#1c2b1e"
features:
  app_home:
    messages_tab_enabled: true
    messages_tab_read_only_enabled: false
  bot_user:
    display_name: Focus
    always_online: true
  slash_commands:
    - command: /focus
      description: Is Focus attached here? Detach, attach, or hand this conversation to an agent.
      usage_hint: "[status | detach 2h | attach | agents | attach <n> | release | help] [message link]"
      should_escape: false
oauth_config:
  redirect_urls:
    - https://api.withfocus.io/v1/connect/slack/callback
  scopes:
    # Granted by each person who connects Slack, so Focus can read and
    # draft in their own conversations.
    user:
      - users:read
      - users:read.email
      - im:history
      - mpim:history
      - groups:history
      - channels:history
      - channels:read
      - groups:read
      - im:read
      - mpim:read
      - im:write
      - search:read
      - chat:write
    # The Focus bot: DMs you when it needs input, answers /focus.
    bot:
      - app_mentions:read
      - commands
      - chat:write
      - im:history
      - im:read
      - im:write
      - users:read
      - channels:history
      - groups:history
settings:
  event_subscriptions:
    bot_events:
      - app_mention
      - message.im
      - message.channels
      - message.groups
    user_events:
      - message.im
      - message.mpim
      - message.channels
      - message.groups
  interactivity:
    is_enabled: true
  org_deploy_enabled: false
  socket_mode_enabled: true
  token_rotation_enabled: false

Also available as a file: slack-manifest.yml. Socket Mode, interactivity, the /focus command and all event subscriptions are already set in it.

2Collect five values from Slack

From Basic Information

  1. Under App Credentials, copy the Client ID, Client Secret and Signing Secret.
  2. Under App-Level Tokens, press Generate Token and Scopes. Name it focus-socket, add the scope connections:write, and press Generate. Copy the token: it starts with xapp-. This is what lets Focus open the Socket Mode connection.

Install it to your workspace

  1. Open Install App (or OAuth & Permissions) and press Install to Workspace, then Allow. If your workspace needs admin approval, your Slack admin approves it first.
  2. Copy the Bot User OAuth Token: it starts with xoxb-.

These are secrets. Paste them only into the Focus dashboard in the next step, never into a chat, a ticket or an email.

3Add them to Focus

  1. Open the Focus dashboard at api.withfocus.io and go to Tools.
  2. Under Workspace apps (admins only), press Configure on Slack app.
  3. Paste the five values and press Save.

Focus checks the tokens and opens the Socket Mode connection within a minute. The row then says Your app and bot.

4Everyone connects their Slack

Each person in your Focus workspace now connects Slack as in the setup guide: Tools, then Connect on the Slack tile. Slack shows your company's app and asks them to allow it. This gives Focus read access to their own conversations, so it can draft replies for them.

Check it works

  • In Slack, open a DM with the Focus app and say hi. It answers while Focus is running on your computer (step 2 of the setup guide).
  • Type /focus status in any conversation. Focus says whether it's attached there.
  • Ask a colleague to DM you. Within a minute a draft reply appears in that DM, visible only to you.
The Slack app row still says "Your app, no bot yet"
The bot token or app-level token is missing. Press Configure and paste both.
The bot doesn't answer
In Slack, check Socket Mode is on and the app-level token has connections:write. If you regenerated a token, paste the new one into Focus.
"redirect_uri did not match" when connecting Slack
Under OAuth & Permissions, the redirect URL must be https://api.withfocus.io/v1/connect/slack/callback. The manifest sets it.
