Questions

Which agents and apps does it work with?

Claude Code, Cursor and Codex for coding, and Slack, Gmail and Zoho Mail for messages.

Does my code or data leave my machine?

Focus never stores your code. Skills your team approves are routed and indexed by Focus, and only you or your team can access them, on approval. Agents read company databases through Outpost, inside your network, and query results never pass through Focus.

What does it cost?

Focus is in early access. Join the waitlist and we'll be in touch.

Will an agent change my code without asking?

Only minor changes, and only once you turn Autopilot on. Major changes (scope, big rewrites, auth, billing, secrets, infrastructure, deploys, migrations) always wait for your OK, and code jobs never touch main and never deploy. How Autopilot works

Who can my agent ask through Relay?

Only people who approved you, agent session to agent session. If their agent isn't sure, it asks them. How Relay works

What size of team is it for?

From one developer up. It's most useful on a team: a skill one person's agent learns reaches everyone's agents.

How do skills get approved?

Each skill has an owner. A skill reaches a colleague's agents only after the owner approves it, and you can see where every skill came from.
